User Guide

osu!taiko Mapping Helper 使用説明書

Version 1.1.0-beta Japanese GitHub

Overview

このツールの役割

osu! のエディタで開いている taiko 譜面を読み取り、SV 編集や一括編集を補助します。操作対象は現在 osu! 側で選択されている .osu ファイル、または同じ曲フォルダ内の全難易度です。

リアルタイムに譜面を読む

起動中の osu! プロセスから、現在開いている曲フォルダ、.osu ファイル名、再生位置、メタデータ、背景画像の情報を取得します。ツール側で譜面名が表示されれば、処理対象を認識できています。

.osu を直接編集する

SV Editor、Utility、BG Setter は .osu ファイルを書き換えます。処理後は osu! のエディタで Ctrl + L を押して、ファイルを再読み込みしてください。

主な機能

SV の適用・削除、ヒットサウンド付与、ノーツ座標変更、タグ編集、設定コピー、再スナップ、背景 Y 位置調整、バックアップ保持数の管理を扱います。

補助情報の確認

Timing Property では、osu! の現在位置に対応する Timing、BPM、SV、Volume、見た目 BPM を確認できます。SV 作業中の値確認に使います。

まず覚えること

このツールの基本は「osu! で対象譜面を開く」「ツールで条件を入力する」「実行する」「osu! で Ctrl + L を押す」です。成功メッセージだけでは osu! 側の表示は更新されないため、再読み込みまでを1セットにしてください。

Start

導入と基本操作

ビルド、起動、タイミング指定、実行後の確認までの共通手順です。

必要な環境

  • Windows
  • osu! stable
  • .NET 8 Desktop Runtime、または .NET 8 SDK
  • ソースからビルドする場合は Visual Studio 2022 以降

起動方法

配布されている実行ファイルがある場合は、基本的に osu!taiko Mapping Helper.exe を実行すれば起動できます。
先に osu! を起動し、エディタで対象の taiko 譜面を開いておくと、ツールが現在の譜面を読み取れます。

ソースから動かす場合だけ、Visual Studio で osu!taiko Mapping Helper.sln を開いてビルドします。
開発者向けのコマンドライン例は次の通りです。

dotnet restore
dotnet build -c Release

基本の流れ

  1. osu! を起動し、エディタで編集したい taiko 譜面を開きます。
  2. osu!taiko Mapping Helper を起動します。
  3. ツール上部の譜面名や背景表示が更新されることを確認します。
  4. メニューから SV Editor、Utility、BG Setter を選びます。
  5. 条件を入力して 実行 または Apply を押します。
  6. 成功メッセージが出たら osu! 側で Ctrl + L を押します。

操作の前提

Timing、SV、Volume などの入力欄は各機能タブで説明します。まずは、ツールが現在の譜面を認識していることと、実行後に osu! 側で再読み込みすることだけ覚えておけば大丈夫です。

SV Editor

SV の適用・削除

上から順番に、Timing、SV、Volume、対象、実行までを説明します。

1. Timing

処理する範囲の始点と終点を指定します。入力は mm:ss:fff 形式、またはミリ秒の整数に対応しています。たとえば 01:23:456 と 83456 はどちらも受け付けます。

Set Start Timing と Set End Timing は、osu! の現在の再生位置をそれぞれ始点・終点に入れるボタンです。

⇔ ボタンは始点と終点を入れ替えます。始点が終点より後ろにある状態では実行時にエラーになります。

2. SV

SV チェックを有効にすると、追加または更新する緑線の SV を指定できます。
SV は 0 より大きい数値を入力します。小数も使用できます。
SV チェックを外した場合は、処理地点の直前にある緑線の SV を参照して、SV 値を明示的には変更しません。

等差モード は始点から終点まで一定量ずつ変化します。等比モード は比率で変化します。

等差モード SV(t) = SV_start + (SV_end - SV_start) * p
等比モード SV(t) = SV_start * (SV_end / SV_start) ^ p

p は範囲内の進行率です。始点では 0、終点では 1 になります。

同じ始点・終点でも、等差は直線的、等比は倍率的に変化します。

3. Volume

Volume チェックを有効にすると、緑線の音量を指定できます。Volume は 5 から 100 の整数で入力します。小数は受け付けません。
Volume チェックを外した場合は、処理地点の直前にある TimingPoint の Volume を参照します。音量を変えずに SV だけを編集したい場合は、Volume を無効にして下さい。

4. 始点に適用

無効にすると、始点ちょうどの対象は処理から除外されます。

5. 終点に適用

無効にすると、終点ちょうどの対象は処理から除外されます。

6. 相対速度変化

設定のアドバンスモードを有効にすると表示されます。通常は入力した SV をそのまま使いますが、相対速度変化では処理地点の直前 SV を基準にして、新しい SV を計算します。
乗算 は (現在の SV - 基準 SV) * 入力 SV + 基準 SV の形で変化します。加算 は現在の SV に入力 SV を足します。

基本的には 特定のオブジェクトのみ と組み合わせて使う機能で、大音符のみに SV を与えたい場合などに有効です。

終点の有効化 を併用すると、相対変化の始点値と終点値を別々に指定できます。終点の有効化を外した場合は、始点側の値を基準にした一定の相対変化として扱う使い方になります。

相対速度変化は、既に置かれている SV の流れを完全に上書きするよりも、「今の SV に対して一部のオブジェクトだけ強調を足す」場面に向いています。全体の SV カーブを新しく作る場合は、通常の SV 指定の方が分かりやすいです。

7. 適用タブ

指定範囲内の対象タイミングに緑線を追加します。
SV や Volume を有効にしている場合は、始点から終点までの位置に応じて値を計算します。

既存の緑線と重なる場合は、処理対象やオフセットに応じて既存緑線を整理しながら出力します。

整理の内容として、対象ノーツの直前から対象ノーツまでの間にある既存緑線は、今回置く線と効果が重複しないよう削除対象になることがあります。ただし、選択していないオブジェクトの効果を戻すために必要な線や、kiai の切り替わりを維持するために必要な線は残す・値を引き継ぐように扱われます。

8. 削除タブ

指定範囲内の緑線を削除します。赤線は削除しません。

削除後は、範囲内や範囲後のスライダーの見た目が崩れにくいよう、必要に応じてsliderLengthを補正します。

9. kiai

チェックを有効にすると、追加する緑線の kiai フラグを ON にします。チェックを外している場合は、基本的に直前の TimingPoint の kiai 状態を引き継ぎます。

そのため、既存の kiai 区間を維持したいだけなら、このチェックボックスを ON にしなくても大丈夫です。

10. オフセット

チェックすると、Objects のみで緑線を置くときに、対象ノーツの少し前へ緑線をずらします。

設定画面のオフセットタイプが 1/16 (1/12) offset の場合は、BPM から 1/16 分の時間を計算して前に置きます。ms offset の場合は、指定したミリ秒分前に置きます。

1/12 を含める を有効にすると、1/12 snap の HitObject が含まれる場合に、前の HitObject の方へ SV 線が近づきすぎないように 1/12 分のオフセットを使います。それ以外の配置では 1/16 が使われます。

Volume 変化を伴う SV 線を設置する場合は、音量変化がノーツの発音タイミングに食い込みにくくなるため、このチェックボックスを使うことを推奨します。

11. 処理対象の選び方

Objects のみHitObject、小節線、BookMark、特定オブジェクトを基準に緑線を追加します。基本モードです。
BeatSnaps赤線の BPM からビートスナップ間隔を計算し、指定範囲内に一定間隔で緑線を追加します。
ノーツがない場所で音量変化のグラデーションを設置したい場合などに使います。赤線をまたぐ場合は次の BPM に合わせて間隔を再計算します。
緑線既存の Inherited Point を基準に SV や Volume を更新します。
既に置いてある緑線のカーブだけを整えたい場合に使います。

Objects のみ の詳細

すべての HitObject範囲内の HitObject と小節線を対象にします。
通常ノーツ、スライダー、スピナーなど、譜面上のオブジェクトに沿って緑線を置きます。
BookMark だけの地点は含まれませんが、BookMark と同じタイミングに実ノーツがある場合は、その実ノーツとして対象になります。
小節線上のみ小節線と同じタイミングにある HitObject だけを対象にします。小節頭のノーツだけに効果を付けたい場合に使います。
小節線上以外小節線と同じタイミングではない HitObject を対象にします。小節頭を避けてノーツ側だけを処理したい場合に使います。
BookMark のみBookMark と同じタイミングにある地点だけを対象にします。BookMark 位置にノーツがある場合は、そのノーツ位置として扱われます。
BookMark 以外BookMark が付いていない HitObject を対象にします。目印を付けた場所だけを避けたい場合に使います。
特定のオブジェクトのみ通常 Don、通常 Kat、大音符 Don、大音符 Kat、Slider、Spinner を個別に選び、選択した種類に一致するオブジェクトだけを処理します。

特定のオブジェクトのみ

選択していない種類のオブジェクトに対応する既存緑線は、基本的に触りません。

このモードでは、選んだオブジェクトの直前または同時刻に緑線を置き、次のノーツ側にも必要な線を自動で置いて SV が意図せず次の区間へ残り続けないようにします。
たとえば特定の大音符だけを強調したい場合、対象の大音符に効果を付け、その後のノーツで元の流れに戻しやすくするための補助が入ります。

12. 実行ボタン

実行 を押すと、現在の入力値と処理対象をもとに .osu ファイルを上書きします。
実行前にバックアップが作成され、成功するとメッセージが表示されます。最後に osu! 側で Ctrl + L を押して再読み込みしてください。

Utility

一括処理と補助機能

Utilityは、SV以外の譜面編集をまとめて行う場所です。

オフセット変更 (all diffs)同じ曲フォルダ内の全 .osu ファイルを対象に、指定ミリ秒分タイミングを移動します。
PreviewTime、Bookmarks、TimingPoints、HitObjects、スピナー終点、動画イベントの開始時刻が移動対象です。
ヒットサウンド設定現在の難易度を対象に、Kat を Clap または Whistle へ統一する機能です。
Don 系のノーツは基本的に変更せず、Kat と大音符 Kat に選択したヒットサウンドを反映します。
ノーツ座標設定現在の難易度のノーツ座標を書き換えます。
Center は X=256 / Y=192 の中央寄せです。Separate は Don、Kat、大音符 Don、大音符 Kat ごとに設定画面の座標を使います。
初期値はすべて X=256 / Y=192 です。Random はノーツごとにランダムな座標を設定します。スライダーは制御点も移動します。
タグエディタ (all diffs)タグ入力欄の内容を、同じ曲フォルダ内の全難易度の Metadata に反映します。
設定コピー (all diffs)現在の難易度から全難易度へ設定をコピーします。
Metadata、BG Position、Preview、Timing Points を選べます。
Timing Points は赤線をコピーし、既存の緑線は各難易度のものを残して出力します。
再スナップ現在の難易度を対象に、指定範囲内のノーツを選択したビートスナップ間隔へ移動します。
全ノーツ対象の場合は、最初のノーツから最後のノーツまでを範囲として扱います。

再スナップの詳しい挙動

赤線ごとに BPM、拍子、barLength からスナップ間隔を計算します。
各スナップ位置の前後半分の範囲に入っているノーツを、そのスナップ位置へ移動します。範囲内に赤線がある場合、次の赤線以降は新しい BPM と拍子で再計算します。

選べる間隔は 1/24、1/36、1/48、1/60 です。譜面の意図に合う最小単位を選んでください。実行前に確認ダイアログが表示されます。

BG Setter

背景Y位置の調整

現在の譜面背景を表示し、osu! の背景イベント行に保存されているY位置を調整します。

何を変更するか

Eventsセクションの背景行にあるYオフセットを書き換えます。画像ファイルそのものを編集する機能ではありません。背景の表示位置だけを変えたいときに使います。

操作

  1. osu! エディタで対象譜面を開きます。
  2. メニューから BG Setter を開きます。
  3. 背景を上下にドラッグしてY位置を調整します。
  4. 実行、または Ctrl + S で保存します。
  5. osu! 側で Ctrl + L を押して確認します。

Timing Property

現在位置の譜面情報を確認する

Timing Propertyは、編集対象を書き換える画面ではなく、osu! の現在再生位置に対応する値を確認するための補助画面です。設定のアドバンスモードを有効にしている場合にメニューへ表示されます。

Timingosu! の現在再生位置を mm:ss:fff 形式で表示します。
BPM現在位置に適用されている赤線のBPMを表示します。
SV現在位置に適用されている SV を表示します。
Volume現在位置に適用されている Volume を表示します。
見た目 BPMBPM、SV、SliderMultiplier をもとに、見た目上のスクロール速度を BPM 相当で表示します。

使い方

osu! エディタで曲を再生またはシークすると、Timing Property の値も更新されます。
SV Editor で複雑なカーブを作る前に、現在の BPM や SV を確認しておくと、入力する SV 値を決めやすくなります。

Settings

設定項目

ツール全体の表示、バックアップ保持数、オフセット方式、ノーツ座標を管理します。

言語設定English / 日本語を切り替えます。
バックアップ保持上限譜面ごとに保持するバックアップ数です。
1から100の整数を指定します。保存時に古いバックアップが整理されます。
オフセットタイプSV Editor のオフセット入力を、スナップ基準またはミリ秒基準に切り替えます。
ノーツ配置設定Separate 使用時の Don、Kat、大音符 Don、大音符 Kat の X / Y 座標を設定します。
X は 0 から 512、Y は 0 から 384 の範囲です。
Unicode対応譜面名表示にTitleUnicode / ArtistUnicodeを使います。
日本語や特殊文字の曲名を表示できます。
アドバンスモード相対速度変化や Timing Property など、追加の編集項目を表示します。

Safety

バックアップと注意事項

このツールは便利ですが、実行時に .osu ファイルを書き換えます。処理の前後で何が起きるかを理解しておくと安心です。

自動バックアップ

SV Editor、Utilityの一部、BG Setter は、上書き前にBackupフォルダへ現在の .osu ファイルをコピーします。
バックアップファイル名には日時が使われ、設定した保持上限を超えた古いファイルは削除されます。

手動バックアップ推奨

大きな範囲へのSV適用、全難易度へのコピー、Resnapなどは影響範囲が広い処理です。
公開前の譜面や作業中のセットでは、曲フォルダごと別の場所へコピーしてから試すと安全です。

実行後の確認

成功メッセージは「ファイルへの書き出しが終わった」ことを示します。osu! エディタの表示は自動では更新されません。
必ず Ctrl + L で再読み込みし、Timing、HitObjects、背景位置を確認してください。

Troubleshooting

困ったとき

よくある症状と確認する場所です。

譜面名や背景が表示されない

osu! が起動しているか、エディタで譜面を開いているか確認してください。
曲フォルダや .osu ファイルが移動・削除されている場合も取得に失敗します。

実行後に変化が見えない

osu! 側で Ctrl + L を押して譜面を再読み込みしてください。
ツールがファイルを書き換えても、エディタ表示は自動更新されません。

Timing の入力でエラーになる

mm:ss:fff 形式、またはミリ秒の整数で入力してください。
始点が終点より後ろの場合もエラーになります。

SVやVolumeの値でエラーになる

SV は正の数、Volume は 5 から 100 の整数が基本です。
相対速度変化の基準 SV も正の値を指定してください。

バックアップを減らしたい

設定画面のバックアップ保持上限を変更して保存します。
1から100の範囲で指定でき、保存後に古いバックアップが整理されます。
